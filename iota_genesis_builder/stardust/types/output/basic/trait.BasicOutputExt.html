fn is_simple_coin(&self, target_milestone_timestamp_sec: u32) -> bool

Infer whether this object can resolve into a simple coin.

Returns true in particular when the given milestone timestamp is equal or past the unix timestamp in a present timelock and no other unlock condition or metadata, tag, sender feature is present.
